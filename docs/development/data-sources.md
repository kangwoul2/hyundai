# 데이터 출처

## 요약

| 구분 | 현재 상태 |
| --- | --- |
| 시설 데이터 | **SAMPLE(합성) 14건만 포함.** 실제 공공데이터는 이번 세션에서 확보하지 못했다 |
| 실제 데이터 확보 시도 | 공공데이터포털 검색(수유시설·수유실)에서 좌표가 있는 전국/지역 파일 데이터셋을 찾지 못했다. 포털 다운로드·OpenAPI는 로그인/인증키 심의가 필요해 자동 수집하지 않았다 |
| 허가 없는 대량 수집 | 하지 않았다 (`tools/collect_facilities.py`는 네트워크를 호출하지 않는다) |

## 번들 스냅샷: `app/src/main/assets/facilities_snapshot.json`

- 생성: `python tools/make_sample_snapshot.py` (결정적, 같은 결과)
- `meta.kind = "SAMPLE"`, 모든 시설 `origin = "SAMPLE"`. 이름은 "샘플 쉼터 NN", 주소는 "합성 데이터 (실제 시설 아님)"이다.
- 좌표만 서울 양재 부근(37.4692, 127.0393) → 대전역/천안아산역 직선 위에서 계산했다. **실제 시설의 위치·속성이 아니다.**
- 목적지(대전역, 천안아산역, 강릉역)의 좌표는 시연용 근사값이다. 강릉역은 시설이 없는 "데이터 없음" 시나리오용이다.
- 의도적 결함: 확인일 1년 초과 1건, 종류 누락 1건, 시설 정보 미상 1건, 수유실 없음 1건 — 추천의 필터·신뢰도·설명을 검증하기 위한 것이다.
- 앱은 SAMPLE일 때 상단에 `SAMPLE 데이터` 태그, 후보 카드에 `샘플 데이터` 태그를 항상 표시한다.

## 데이터 품질 지표 (번들 스냅샷, `tools/collect_facilities.py --report`)

| 지표 | 값 |
| --- | --- |
| 전체 시설 수 | 14 |
| 좌표 유효 | 14 (100%) |
| 중복 id | 0 |
| 종류 정보 누락 | 1 (7.1%) |
| 시설 정보 미상 | 1 |
| 출처별 | SAMPLE 14 |
| 확인일 분포 | 2025-06-01 ~ 2026-10-30 |
| 사용자 확인 기록 비율 | 0 (앱 내 이용 기록은 기기에만 저장, 시설 데이터로 환류하지 않음) |

위 수치는 **합성 데이터에 대한 값**이며 실제 시설 데이터의 품질을 의미하지 않는다.

## 실제 데이터로 교체하는 절차 (사용자 행동 필요)

1. 공공데이터포털(data.go.kr) 또는 지자체 포털에서 수유시설 파일 데이터를 찾고 **이용허락범위·갱신주기**를 확인한다. 인증키/로그인이 필요하면 사용자가 신청한다.
2. CSV를 `data/raw/`(gitignore 대상)에 내려받는다.
3. `python tools/collect_facilities.py --csv data/raw/<파일>.csv --source "<데이터셋명>" --verified-on <확인일> --map name=<열> lat=<열> lon=<열> address=<열> kind=<열> --demo-center <lat,lon> --radius-km 60 > app/src/main/assets/facilities_snapshot.json`
4. 목적지 목록(`destinations`)을 시연 지역에 맞게 채운다.
5. `python tools/collect_facilities.py --report ...`로 품질 지표를 갱신하고 이 문서를 고친다.
6. 수유실 외 속성(기저귀 교환대 등)은 원본에 있을 때만 매핑한다. 없는 속성을 추정해 채우지 않는다.

## 이용 조건 메모

- 공공데이터포털 표준데이터는 대체로 "이용허락범위 제한 없음"이나 **데이터셋별로 다르므로** 사용 전 개별 확인한다.
- Pleos SDK 라이선스(42dot): SDK 복제·재배포·역컴파일 금지. 이 저장소는 SDK 바이너리/소스를 포함하지 않으며 Maven 좌표만 참조한다.
