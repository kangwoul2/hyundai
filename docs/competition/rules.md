# 현대자동차그룹 차량용 앱 개발 공모전 — 공식 규칙

확인일: 2026-11-05. 이 문서의 날짜와 제출 방식은 **공모전 공식 사이트를 기반으로 직접 재확인**했다. 변경 공지가 나오면 공식 사이트가 우선이다.

## 1. 어떤 대회인가

현대자동차그룹의 Pleos Connect 환경에서 자동차의 상태와 이동 맥락을 활용하는 차량용 앱을 만드는 공모전이다. 대학(원)생, 일반인, 스타트업이 참가할 수 있고 개인 또는 대표자를 포함한 최대 5인 팀으로 지원한다. 시상은 대학생 부문과 일반(스타트업 포함) 부문으로 나뉜다. SSAFY 교육생이라는 사실만으로 대학생 부문이 확정되는 것은 아니므로 실제 학적 기준 확인이 필요하다.

## 3. 1차 필수 제출과 선택 제출

**필수:** 공식 접수양식(기획서) 작성본과 참가자별 개인정보 수집·이용 동의서. 접수양식이 곧 기획서다. 공모전 이메일로 발송해야 하며 GitHub에 파일을 올리는 것만으로는 접수되지 않는다.

- 접수: `appdevchallenge@hyundai-partners.com`
- 제목: `[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명`
- 팀 참가 시 팀원 전원 개별 서명 및 날짜, 대표자가 전원 CC.
- 수정 제출 시 원래 이메일 주소로 전체 자료를 재전송하고, 제목은 `[수정제출] [차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명`. 마감 전 마지막 제출본이 최종본.

**선택/가산점:** 프로토타입 시연 영상, 소스 코드와 APK를 포함한 GitHub 저장소 링크. 숏폼은 별도 특별상이며 본상 가산점이 아니다.

GitHub 제출 시:
1. 저장소에 실행 가능한 소스 코드를 올린다.
2. release APK를 `apk/` 폴더에 올린다. 형식: `팀명_앱이름_release.apk`.
3. 파일이 용량 제한을 초과하면 GitHub Releases를 사용하고 링크를 안내한다.
4. README에 앱 이름과 한 줄 소개, 실행 방법, 테스트 환경, APK 위치를 적는다.
5. Private 저장소도 허용되지만 공지된 심사용 계정을 collaborator로 초대하고 실제 접근을 확인해야 한다. 개인 Private 저장소의 collaborator는 쓰기 권한도 얻을 수 있으므로 유의한다.
6. 현재 저장소는 문서만 있으므로 '가산점용 구현 결과물' 상태가 아니다.

공식 안내: https://appdevchallenge.auto-hmg.io/guide/submission

## 5. 시상과 사업화

대상 1,000만원(부문별 1팀), 최우수상 600만원(부문별 1팀), 우수상 400만원(부문별 2팀), 아이디어 특별상 150만원(부문통합 2팀), 본상 총상금 5,100만원. 숏폼 특별상 50만원은 별도다.

최종 선정된 10팀은 전시·시연용 APK를 제출하고 2027년 2월 공식 행사에 참가한다. Pleos App Market 입점 지원은 가능하지만 실제 입점·배포가 보장되는 것은 아니다.

## 6. 개발 조건과 주의점

- Android API 28 이상, Gradle 8.0 이상, Java 또는 Kotlin.
- Pleos SDK: Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation. 기능별 제공 조건과 권한 확인.
- 차량 제어 권한은 일반적인 읽기 권한과 다를 수 있으므로 공식 API와 심사 지침 확인 전에는 사용 계획을 확정하지 않는다.
- 접수양식 5번 '개발 계획'에는 주요 구현 범위와 SDK/API 활용 계획을 구체적으로 작성한다.
- 실제 참가 부문, 동의서 양식, 앱 등록 권한, 사용자 데이터 정책은 최종 제출 전에 별도 검증한다.
