# BabyRelay — 제품 요구사항 (PRD)

작성일 2026-11-05 · 상태: **MVP 구현됨(Replay 기준 검증), 실제 Pleos 연동은 `docs/development/sdk-integration.md` 참조**

## 1. 한 줄 소개

아기와의 이동에서 필요한 정차를 계획하고, 차량 내비게이션과 연결하며, 목적지 도착 후 돌봄 정보를 다음 보호자에게 이어주는 차량용 앱.

## 2. 대상 사용자와 문제

| 항목 | 내용 |
| --- | --- |
| 핵심 사용자 | 생후 3~12개월 아이와 1~3시간 가족 방문·장거리 이동을 하는 보호자 |
| 문제 1 | 출발 전에 아기에게 필요한 휴식 장소(수유/기저귀 교환)를 찾기 번거롭다 |
| 문제 2 | 찾은 장소를 내비게이션에 다시 등록해야 한다 |
| 문제 3 | 이동 중 돌봄 기록이 목적지의 다음 보호자에게 전달되지 않는다 |

> 위 문제는 기획 가설이다. 실제 사용자 조사/측정 데이터는 아직 없으며 수치를 만들어 내지 않는다.

## 3. 핵심 가치와 차량 특화성

기존 서비스의 수유시설 검색·메모·체크리스트를 단순 결합하지 않는다. 핵심은 세 가지다.

1. 보호자가 계획한 휴식 장소를 **차량 내비게이션 경유지로 연결**한다 (NaviHelper `requestRouteWithWaypoints`).
2. **경유지·목적지 도착 이벤트**(`onWayPointArrived`, `onDestinationArrived`)를 돌봄 여정 상태와 연결한다.
3. 최종 도착 시 인계에 필요한 정보를 **자동으로 구성**한다.

기술적 차별점: **차량의 이동 상태 변화가 앱의 다음 기능을 결정하는 상태 기반 서비스.** 휴대폰 앱은 내비 경유지 등록·도착 이벤트를 받을 수 없다. 또한 화면 조작은 플랫폼의 `CarUxRestrictions`로 잠긴다.

## 4. 기능 범위 (MVP 고정)

| ID | 기능 | 구현 상태 | 검증 |
| --- | --- | --- | --- |
| A1 | 아기 동승 여행 시작 | 구현 | 단위·에뮬레이터(REPLAY) |
| A2 | 목적지: 내비에서 가져오기 / 직접 선택 | 구현 | 단위·에뮬레이터(REPLAY). 내비 조회는 Pleos 미검증 |
| A3 | 다음 휴식 희망 시각, 필요 시설 조건 | 구현 | 단위·에뮬레이터 |
| A4 | 후보 최대 2개 + 추천 이유 | 구현(규칙 기반, 직선거리) | 단위 14건 |
| A5 | 경유지 등록 요청, 실패 시 장소 정보 제공 | 구현 | 단위(실패·미확인·오류) / Pleos 실연동은 G1 |
| B1 | 이동 중 상태·선택 장소 표시, 입력 제한 | 구현 | 단위·에뮬레이터 |
| C1 | 경유지 도착 이벤트 → 상태 갱신 | 구현 | 단위·REPLAY / Pleos 콜백은 G1 |
| C2 | 돌봄 기록(수유/기저귀/시설 이용 가능·불가), 시각·출처 저장 | 구현 | 단위·계측(Room) |
| D1 | 목적지 도착 이벤트 → 도착 상태 | 구현 | 단위·REPLAY / Pleos 콜백은 G1 |
| D2 | 인계 카드 생성·확인·인계 없이 종료 | 구현 | 단위·에뮬레이터 |

## 5. 비범위 (다시 포함하지 않음)

Spring Boot 서버, 다중 사용자 인증, 모바일 웹, 실시간 보호자 동기화, 상대 보호자 인증, ISOFIX/카시트 안전 판정, 신생아 자동 감지, 운전 습관 점수, AI 챗봇, Kafka/Redis/Kubernetes, 의료적 수유 시간 추천.

선택 기능(텍스트 QR 인계 카드, TTS, 준비물 체크리스트 확장, ETA 후보 비교, 신뢰도 표시)은 **구현하지 않았다.** 필수 범위 검증이 우선이었다.

## 6. 안전·개인정보 요구

- 주행 제한(`CarUxRestrictions.isRequiresDistractionOptimization`)이 true이거나 알 수 없으면 시설 선택, 목적지·조건 변경, 기록 입력, 인계 수정을 잠근다.
- 경유지 도착 이벤트만으로 주차/정차를 가정하지 않는다.
- 저장하는 것: 목적지·경유지 이름, 돌봄 기록(종류·시각·출처), 전달 물품(프리셋). 저장하지 않는 것: 아이 이름·사진·연락처, 사용자 현재 위치·이동 경로 이력. 서버로 전송하지 않는다. 종료된 여정은 7일 뒤 삭제한다.
- 자유 텍스트 입력은 없다(운전 중 키보드 입력 금지 원칙, 개인정보 유입 방지).

## 7. 성공 기준(공모전 제출용, 측정 가능)

- Gradle 빌드·JVM 테스트·계측 테스트 통과 로그 보존 (`docs/testing/`)
- REPLAY 전 과정(계획→추천→등록→이동→휴식 기록→도착→카드) 에뮬레이터 재현
- 실제 Pleos 에뮬레이터에서 NaviHelper 연결·경로 요청·도착 콜백 시험 결과 기록(성공/실패 모두)
- release APK, 소스, 스크린샷, 시연 방법
